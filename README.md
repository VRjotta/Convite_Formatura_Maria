# Convite de formatura – Maria Clara

Site estático (HTML, CSS e JavaScript puros, sem instalar nada). O `index.html` fica na raiz.

## Abrir no VS Code
`Arquivo > Abrir Pasta…` e escolha esta pasta. Com a extensão **Live Server**, clique em *Go Live*.

## Hospedar no GitHub Pages
1. Crie um repositório novo no GitHub (sugestão de nome: `convite-maria-clara`) e envie todo o conteúdo desta pasta.
2. `Settings > Pages > Build and deployment`: Source = `Deploy from a branch`, branch `main`, pasta `/ (root)`. Salve.
3. Em 1 a 2 minutos o convite fica em `https://SEU-USUARIO.github.io/convite-maria-clara/`.

## Editar dados
No fim do `index.html`, procure `const CONFIG` (data, hora, local e link do formulário de confirmação).
